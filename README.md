## 🚀 Features

- **Responsive Design**: Mobile-first approach, works on all devices
- **Modern UI**: Gradient backgrounds, smooth animations, and hover effects
- **Organized Code**: Separate HTML, CSS, and JavaScript files
- **Smooth Scrolling**: Navigate sections smoothly

- **Mobile Menu**: Responsive navigation for mobile devices

- **SEO Optimized**: Proper meta tags and semantic HTML

## 📋 Usage

1. **To view the website locally:**
   - Open `index.html` in your web browser
   - Or use a local server (recommended for best results)

2. **Using Python HTTP Server:**
   ```bash
   python -m http.server 8000
   ```
   Then visit: `http://localhost:8000`

3. **To customize:**
   - Edit HTML content in `index.html`
   - Modify styles in `css/styles.css`
   - Add functionality in `js/script.js`
   - Add images to the `images/` folder

## 🎨 Customization Guide

### Colors
Main colors used (defined in `styles.css`):
- Primary Blue: `#003366`
- Secondary Blue: `#0066cc`
- Accent Yellow: `#ffcc00`
- Purple Gradient: `#667eea` to `#764ba2`

### Fonts
- Headings: Poppins (Google Fonts)
- Body: Roboto (Google Fonts)

### Adding Images
1. Place your images in the `images/` folder
2. Reference them in HTML: `<img src="images/your-image.jpg" alt="Description">`
3. Or in CSS: `background-image: url('../images/your-image.jpg');`
